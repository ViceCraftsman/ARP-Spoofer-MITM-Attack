# Contributing to ARP-Spoofer-MITM-Attack

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Run `dotnet build ARP-Spoofer-MITM-Attack.sln`.
4. Run `dotnet test ARP-Spoofer-MITM-Attack.sln`.

## Coding Standards

- Follow standard C# naming conventions.
- Keep domain logic inside `Core`.
- Add unit tests for new services and public methods.
- Use structured logging instead of `Console.WriteLine`.

## Pull Request Process

1. Create a feature branch.
2. Write clear commit messages.
3. Ensure all tests pass.
4. Open a pull request with a concise description.

All contributions must be for authorized testing, CTF, or educational purposes.
